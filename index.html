先生・おうちの方へ
  • 重心は「あつさと材質が一様な板」として計算（面積重心）。
  • SVGは mm 単位。赤 = 切断、青 = けがき、線幅 0.1 mm。加工機ソフト側で色ごとに出力設定。
  • あなの直径はレーザの焼きしろ（カーフ）ぶん大きく仕上がる。きつめにしたい場合は「じぶんで決める」で 0.1〜0.2 mm 小さく。
  • 読みこみ：SVG（path / polygon / rect / circle / ellipse）、DXF（LWPOLYLINE / POLYLINE / CIRCLE / LINE・ARCの連結）。内側の輪郭は「あな」として計算。はなれた形が複数あれば、それぞれの重心にしるし。
  • 物の写真（カラー）：わくのふちの色を背景とみなし、色のちがうかたまりを物体として輪郭化。無地に近い背景・背景とちがう色の物・真上からの撮影が向く。こいかげは物の一部になりやすい。AIモデル不使用、端末内で処理。
  • 線の絵の写真・画像（PNG / JPEG など）：白い紙にこい線でかき、紙だけが大きくうつるように撮影。二値化 → かすれ・とぎれをつなぐ → 線の内側を形として輪郭化。線が画面のふちにかかる形は読みこめない。確認画面でトリミング可（机・かげ・不要な線を外す。切りぬいた範囲を高解像度で再処理）。寸法情報がないので「大きさ」で指定。
  • PDF：A4 たて、ベクター、色と線幅は SVG と同じ。「複製」を入れると（SVG も A4 サイズで同じならびに）、重ならないようにできるだけ多く敷きつめ、左下の余白にこ数（Copies）を表示。ふちの余白 5 mm。形が1種類のときは、数学の「格子充填」「二重格子充填」（形と 180° 回転した形を組にして規則的に並べる。凸図形なら面積の √3/2 ≒ 86.6% 以上うまることが証明されている）で規則的にならべ、あまった所を個別に回転させた形でうめる。形が複数のときは1こずつ回転させて順につめる。最適解とはかぎらない。
  • データは端末内だけで処理。送信なし。
