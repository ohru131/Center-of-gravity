# 変わりゴマ メーカー

科学教室（小中学生向け）用Webアプリ。一筆書きの閉じた図形の重心を求め、レーザ加工機用SVGを出力。

## 使い方

`index.html` をブラウザで開くだけ。ビルド・サーバ不要、オフライン動作。GitHub Pages でもそのまま公開可。

1. 形をつくる：指・マウス・ペンで一筆書き（自動で閉じる）／ファイル読みこみ／見本。複数かける。形の中にかくと穴
2. 重心をさがす：タップで予想 → 答え表示（予想とのずれを mm 表示）
3. まわしてみる：重心まわり・予想点まわりの回転を比較
4. コマにする：大きさ・軸の太さを指定して SVG ダウンロード

## 読みこみ対応

- SVG：`path` / `polygon` / `polyline` / `rect` / `circle` / `ellipse`（transform 対応、`use` は非対応）
- DXF：`LWPOLYLINE`（bulge 対応）/ `POLYLINE` / `CIRCLE` / `LINE`・`ARC` の連結（`SPLINE`・`ELLIPSE` は非対応）
- 写真・画像（PNG / JPEG など、スマホはカメラ撮影可）：適応的二値化 → かすれ・微小なとぎれを連結 → 線の内側をぬりつぶして輪郭化。確認画面でトリミング・感度・つなぐ強さを調整
- 物の写真（カラー）：切りぬきわくのふちの色を背景として学習（k-means）→ 色のへだたりを大津の方法で二分 → 物体のかたまりを輪郭化。線画か物体かは自動判定、手動切りかえ可
- 内側の輪郭は穴として計算。閉じた図形が複数あれば、図形ごとに重心を計算してしるしを付ける

## 出力SVG

- 単位 mm、余白 5 mm、線幅 0.1 mm
- 赤 `#ff0000` = 切断（外形・軸穴）、青 `#0000ff` = けがき（十字マーク）

## 計算

厚さ・材質が一様な板と仮定した面積重心（シューレース公式）。重心が図形の外にある場合・穴がふちに近い場合は警告（外にある図形にはしるしを出力しない）。
